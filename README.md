# lyrics_bokaro

> "가사 모음집"

## Overview

### Goal
- 보컬로이드 가사 모음 사이트

## Tech
- FE: HTML, CSS
- BE: JavaScript
- DB: Json

## How to Run?
아래 바로가기를 클릭하거나 링크를 복사에 웹 주소란에 붙여넣기 합니다.

[바로가기](https://minty-developer.github.io/lyrics_bokaro)

링크:
```https://minty-developer.github.io/lyrics_bokaro```

## Notice
- 위 사이트는 **수익창출을 하지 않으며**, 모든 노래의 영상의 저작권은 영상 저작자에게 있음을 알립니다.
- 위 웹사이트의 CSS, JavaScript는 [Gemini](https://gemini.google.com/app?hl=ko)와 함께 제작했습니다.
- 가사 발음 작성과 번역은 **minty-developer**가 직접 했습니다.
- 가사의 출처는 [나무위키](https://namu.wiki/w/%EB%82%98%EB%AC%B4%EC%9C%84%ED%82%A4:%EB%8C%80%EB%AC%B8)입니다.
